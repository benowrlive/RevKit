    28→    28→## 1. What is RevKit?
    29→    29→
    30→    30→A **desktop app** that helps researchers do Cochrane systematic reviews. Supports all 5 Cochrane review types:
    31→    31→
    32→    32→| Type | Use case | Data entry | Meta-analysis | RoB tool |
    33→    33→|---|---|---|---|---|
    34→    34→| **Intervention** | Does X work for Y? | 2×2 / mean+SD / GIV | MH, Peto, IV, DL | RoB 2 + ROBINS-I |
    35→    35→| **DTA** | How good is test X for disease Y? | TP/FP/FN/TN | Univariate logit + HSROC | QUADAS-2 |
    36→    36→| **Methodology** | How good is method X? | Same as intervention | Same as intervention | ROBINS-I |
    37→    37→| **Overview** | Summary of multiple reviews | Linked review IDs | Extracted effect sizes | AMSTAR-2 lite |
    38→    38→| **Flexible** | Custom | User-defined | Optional | Optional |
    39→    39→
    40→    40→**Sub-types**: Prognosis / Etiology / Qualitative — implemented as a tag, not separate code paths.

   189→   189→- **Working state** = in-memory SQLite (developer experience of Prisma + queries)

   191→   191→
   192→   192→On Open: JSON file → in-memory SQLite. On Save: in-memory SQLite → JSON file.

   194→   194→## 6. `.revkit` project file format
   195→   195→
   196→   196→A `.revkit` file is a UTF-8 JSON file:
   197→   197→
   198→   198→```json
   199→   199→{
   200→   200→  "format": "revkit-1",
   201→   201→  "formatVersion": "1.0.0",
   202→   202→  "createdAt": "2026-08-10T12:00:00Z",
   203→   203→  "updatedAt": "2026-08-10T15:30:00Z",
   204→   204→  "appVersion": "0.1.0",
   205→   205→  "review": {
   206→   206→    "id": "uuid-v4",
   207→   207→    "title": "Rapid diagnostic tests for uncomplicated P. falciparum malaria",
   208→   208→    "researchQuestion": "...",
   209→   209→    "type": "DTA",
   210→   210→    "subType": null,
   211→   211→    "status": "draft",
   212→   212→    "phase": "extraction",
   213→   213→    "comparisons": [...],
   214→   214→    "studies": [...],
   215→   215→    "references": [...],
   216→   216→    "robAssessments": [...],
   217→   217→    "prismaFlow": {...}
   218→   218→  }
   219→   219→}
   220→   220→```
   221→   221→
   222→   222→**Rules:**
   223→   223→- On **open**: validate against JSON schema (zod). If `formatVersion` is older → run migrations. If corrupt → offer recovery.
   224→   224→- On **save**: always write current `formatVersion`; never silently downgrade.
   225→   225→- On every save, first copy current file to `<filename>.revkit.bak` (overwrite).
   226→   226→- v1 keeps PDFs **separate** (stored as absolute path strings in `study.pdfPath`). v1.1 will add optional PDF-embedding.

   452→   452→## 10. Critical statistics formulas (for Phase 4)
   453→   453→
   454→   454→### Effect measures (per-study, dichotomous 2×2)
   455→   455→
   456→   456→| Cell | Layout |
   457→   457→|---|---|
   458→   458→| `a` (events treatment) | `b` (non-events treatment) | `n1 = a+b` |
   459→   459→| `c` (events control) | `d` (non-events control) | `n2 = c+d` |
   460→   460→| `N = n1+n2` |
   461→   461→
   462→   462→**Risk Ratio (RR):**
   463→   463→```
   464→   464→RR = (a / n1) / (c / n2)
   465→   465→log(RR) = log(a/n1) - log(c/n2)
   466→   466→SE(log RR) = √(1/a - 1/n1 + 1/c - 1/n2)   (Katz)
   467→   467→```
   468→   468→Zero-cell: add 0.5 to all cells of any study with a zero cell (for MH/IV; never for Peto).
   469→   469→
   470→   470→**Odds Ratio (OR):**
   471→   471→```
   472→   472→OR = (a × d) / (b × c)
   473→   473→log(OR) = log(a) + log(d) - log(b) - log(c)
   474→   474→SE(log OR) = √(1/a + 1/b + 1/c + 1/d)   (Woolf)
   475→   475→```
   476→   476→Zero-cell: add 0.5 to all cells of any study with a zero cell.
   477→   477→
   478→   478→**Risk Difference (RD):**
   479→   479→```
   480→   480→RD = (a/n1) - (c/n2)
   481→   481→SE(RD) = √( (a×(n1-a))/n1³ + (c×(n2-c))/n2³ )
   482→   482→```
   483→   483→No continuity correction needed.
   484→   484→
   485→   485→**Peto OR:**
   486→   486→```
   487→   487→O = a
   488→   488→E = (n1 × (a+c)) / N
   489→   489→V = (n1 × n2 × (a+c) × (b+d)) / (N² × (N-1))
   490→   490→logOR_peto = (O - E) / V
   491→   491→SE(logOR_peto) = 1 / √V
   492→   492→```
   493→   493→No continuity correction (Peto handles sparse data natively).
   494→   494→
   495→   495→### Continuous — Mean Difference (MD)
   496→   496→```
   497→   497→MD = mean1 - mean2
   498→   498→SE(MD) = √(sd1²/n1 + sd2²/n2)
   499→   499→```
   500→   500→
   501→   501→### Continuous — SMD (Hedges' g)
   502→   502→```
   503→   503→SMD_raw = (mean1 - mean2) / spooled
   504→   504→spooled = √( ((n1-1)×sd1² + (n2-1)×sd2²) / (n1+n2-2) )
   505→   505→J = 1 - 3/(4×(n1+n2-2) - 1)
   506→   506→SMD = J × SMD_raw
   507→   507→SE(SMD) = √( (n1+n2)/(n1×n2) + SMD² / (2×(n1+n2)) )
   508→   508→```
   509→   509→
   510→   510→### Pooling methods
   511→   511→
   512→   512→**Inverse Variance (IV, fixed):**
   513→   513→```
   514→   514→w_i = 1 / SE_i²
   515→   515→pooledEffect = Σ(w_i × θ_i) / Σ(w_i)
   516→   516→pooledSE = √(1 / Σ(w_i))
   517→   517→CI = pooledEffect ± z × pooledSE   (z=1.959964 for 95%)
   518→   518→z_score = pooledEffect / pooledSE
   519→   519→pValue = 2 × (1 - Φ(|z|))
   520→   520→```
   521→   521→
   522→   522→**Mantel-Haenszel (MH):** See Cochrane Handbook v6.4 Ch. 10.4.2 — implement Robins-Greenland SE for OR, Greenland-Robins SE for RR.
   523→   523→
   524→   524→**Peto:** `pooledLogOR = Σ(O-E) / Σ(V); SE = 1/√(ΣV)`
   525→   525→
   526→   526→**DerSimonian-Laird (DL, random):**
   527→   527→```
   528→   528→Q = Σ w_i × (θ_i - θ_fixed)²    (Cochran's Q)
   529→   529→df = k - 1
   530→   530→C = Σ w_i - (Σ w_i²)/Σ w_i
   531→   531→τ² = max(0, (Q - df) / C)
   532→   532→w_i_random = 1 / (SE_i² + τ²)
   533→   533→pooledEffect = Σ(w_i_random × θ_i) / Σ(w_i_random)
   534→   534→pooledSE = √(1 / Σ(w_i_random))
   535→   535→```
   536→   536→
   537→   537→### Heterogeneity
   538→   538→
   539→   539→```
   540→   540→Q = Σ w_i × (θ_i - θ_fixed)²
   541→   541→df = k - 1
   542→   542→pValue = 1 - χ²_cdf(Q, df)
   543→   543→I² = max(0, (Q - df) / Q)        // 0..1 (25% low, 50% mod, 75% high)
   544→   544→τ² = DL estimator (above)
   545→   545→H = √(Q / df)
   546→   546→```
   547→   547→
   548→   548→### DTA stats (Phase 4)
   549→   549→
   550→   550→**Univariate pooling for Sensitivity (logit transform):**
   551→   551→```
   552→   552→For each study: logit_sens = log(TP / FN) ≈ log(TP/(TP+FN) / (1 - TP/(TP+FN)))
   553→   553→SE(logit_sens) = √(1/TP + 1/FN)
   554→   554→Pool via IV (fixed) or DL (random).
   555→   555→Back-transform: sens = 1 / (1 + exp(-logit_sens))
   556→   556→```
   557→   557→Same for Specificity (use TN, FP).
   558→   558→
   559→   559→**DOR (Diagnostic Odds Ratio):**
   560→   560→```
   561→   561→DOR = (TP × TN) / (FP × FN)
   562→   562→log(DOR) pooled via IV or DL.
   563→   563→```
   564→   564→
   565→   565→**HSROC (simplified):**
   566→   566→```
   567→   567→logit(TPR) = α + β × logit(FPR)
   568→   568→Estimate α (threshold) and β (slope) via weighted least squares.
   569→   569→If β ≈ 1 → symmetric SROC; summary point at (α/2, α/2).
   570→   570→```
   571→   571→(Full bivariate model needs R — out of scope for v1.)
   572→   572→
   573→   573→### Forest plot rendering rules
   574→   574→
   575→   575→- Box **area** (not side length) ∝ weight: `boxArea_i = (w_i / Σ w_j) × maxBoxArea; boxSide_i = √boxArea_i`.
   576→   576→- Subgroup + overall diamonds: center at pooled effect, width = CI, height ~12px.
   577→   577→- **Log axis** for ratio measures (RR/OR/HR/Peto OR); **linear** for differences (RD/MD/SMD).
   578→   578→- Tick marks: powers of 2 for log (0.125, 0.25, 0.5, 1, 2, 4, 8); round numbers for linear.
   579→   579→- Null effect line: x=1.0 (log) or x=0.0 (linear).
   580→   580→- Out-of-range CIs: arrowheads pointing outward.
   581→   581→
   582→   582→### Anti-patterns (forbidden)
   583→   583→
   584→   584→- ❌ `Math.log(0)` → -Infinity. Apply continuity correction FIRST.
   585→   585→- ❌ Negative I². Always `max(0, ...)`.
   586→   586→- ❌ Continuity correction for Peto.
   587→   587→- ❌ `1 - Φ(z)` for two-tailed p. Use `2 × (1 - Φ(|z|))`.
   588→   588→- ❌ Compute CI on original scale for ratio measures. Compute on log scale, then `exp()` the bounds.
   589→   589→
